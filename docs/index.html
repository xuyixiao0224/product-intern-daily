Product Intern Daily · 产品实习日报

Product Intern Daily（产品实习日报）是一个开源的产品实习岗位聚合工具。 它每天采集小红书产品实习帖，OCR 正文、图片和评论，抽取公司、岗位、Base、投递邮箱与在招状态，去重后生成岗位表和每日邮件。

常见问题

Product Intern Daily 会不会被小红书封号？
Product Intern Daily 用小号采集，2–3 并发、3–8 秒间隔；遇到 461 或验证码立即停止，Cookie 不进 GitHub Secrets。
用 Product Intern Daily 需要 API Key 吗？
不一定。手动模式由本地 Agent 自行抽取，不强制 API Key；只有自动每日任务才需要 OpenAI-compatible API。
只写在图片或置顶评论里的邮箱能抓到吗？
能。Product Intern Daily 会 OCR 正文、全部图片、评论和置顶评论图片，默认做原图 + 180° 旋转 + 水平/垂直翻转。
数据多久更新一次？
每天一次，19:00 采集、20:00 发邮件。旧岗位更新不重复计入新增。
能商用吗，能拿去卖岗位表吗？
不能。License 为 PolyForm Noncommercial 1.0.0，明确禁止商业销售、付费岗位表和托管服务。
